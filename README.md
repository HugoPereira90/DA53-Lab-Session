# Projet : TP sur le fonctionnement d'un compilateur

Ce dépôt contient les Travaux Pratiques (TP) d'un module sur le fonctionnement des compilateurs. Vous y trouverez des implémentations, des exemples, et des explications sur les concepts fondamentaux du processus de compilation.

## Contenu du projet

Chaque répertoire de ce projet correspond à un TP spécifique, abordant une étape ou un aspect précis du fonctionnement d'un compilateur. Voici un aperçu des dossiers principaux :

- **TP1 - Analyse lexicale** :
  - Implémentation d'un analyseur lexical (lexer) pour du TinyBasic.
  - Extraction des tokens à partir d'un code source donné.
